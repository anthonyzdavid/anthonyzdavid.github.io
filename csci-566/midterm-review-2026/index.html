QUESTION 01 / 56 · Training#1

Overfitting and the generalization gap

Training accuracy is 100%, but test accuracy is 46%. Which proposed remedy is least common: L2, changing tanh to sigmoid, a smaller network, or BatchNorm?

Archived key: B

B · Replacing tanh with sigmoid is not a standard overfitting remedy.

Why this answer follows

  1. The network fits the training set perfectly but makes many mistakes on unseen examples. This is consistent with overfitting, although a distribution shift or a bad split could also create a gap.
  2. L2 adds a cost for large weights; a smaller model limits capacity. Both can discourage memorizing training-specific details. BatchNorm can introduce a useful regularizing effect during training, although it does not guarantee better generalization.
  3. Tanh and sigmoid both saturate. Swapping one for the other does not directly constrain model complexity or increase the training information. Choose changes using validation performance, then evaluate the final choice on test.

What to watch for

A large gap is evidence to investigate, not a proof that every regularizer will help. B is the least standard remedy among these choices.

QUESTION 02 / 56 · CNNs#2

Max pooling and computation

Which layer is expected to use the fewest floating-point arithmetic operations: convolution plus bias, max pooling, sigmoid, or BatchNorm?

Archived key: B

B · Max pooling mainly compares values.

Why this answer follows

  1. A pooling window keeps its largest value. For [1, 7, 3, 2], three comparisons find 7; no learned dot product or exponential is required.
  2. Convolution computes many multiplications and additions. Sigmoid computes 1/(1 + exp(−x)). BatchNorm performs centering, scaling, and usually a learned affine transformation.
  3. This is an operation-count comparison under the intended comparable-layer setting. Actual wall-clock latency also depends on tensor sizes, memory traffic, hardware, and implementation. The question supplies no shapes that would establish a universal runtime ranking.

What to watch for

Few arithmetic FLOPs does not mean zero work: comparisons, memory reads, and output writes still cost time.

QUESTION 03 / 56 · Gradients#3

Zero initialization and gradient flow

All network parameters start at zero. After one forward/backward/update step, what can happen to the first-layer weights?

Archived key: A

Read with care. Architecture-dependent key: A in the archive; D for the first update of a standard all-zero multilayer network.

Printed A is possible for some models; the question does not specify enough to make it universal.

Why this answer follows

  1. For a one-layer linear model, L = (wᵀx − y)² gives ∇w L = 2(wᵀx − y)x. At w = 0, the update is w ← 2ηyx. With y = 1 and x = (1, −1), the new weights are (2η, −2η), so both signs are possible.
  2. For a conventional multilayer network, the first hidden-layer gradient contains the next layer’s weight matrix: δ₁ = (W₂ᵀδ₂) ⊙ g′(z₁). If W₂ = 0, then δ₁ = 0 on this first pass. Consequently W₁ remains zero after that simultaneous update: option D in this setting.
  3. Even when identical hidden units later receive nonzero updates, symmetric units can remain identical. Random initialization breaks that symmetry; it is not a promise that every weight will have a particular sign.

Primary reference: Stanford CS231n: initialization and symmetry ↗

What to watch for

B and C impose an unjustified fixed sign. A needs an architecture that permits a nonzero first-layer gradient; zero initialization alone does not ensure that.

QUESTION 04 / 56 · CNNs#4

Parameters in one 1×1 filter

A 64×64 RGB image has 3 channels. How many weights does one standard 1×1 convolutional filter have, without bias?

Archived key: 3

3 weights.

Why this answer follows

  1. One output at a position combines the three input-channel values: y = w₁x₁ + w₂x₂ + w₃x₃.
  2. Count kernel height × kernel width × input channels = 1×1×3 = 3. There is one output filter and no bias.
  3. The same three weights are reused at all 64×64 locations. That produces many activations but does not add trainable parameters. With F such filters, the weight count would be 3F.

What to watch for

Do not multiply by 64×64 when counting shared parameters. A 1×1 kernel still spans all input channels in a standard dense convolution.

QUESTION 05 / 56 · Gradients#5

Gradient norm clipping

Which listed method directly addresses exploding gradients? The last option rescales a gradient using a predefined norm threshold.

Archived key: D

D · Clip the gradient norm.

Why this answer follows

  1. An exploding gradient can produce an excessively large update Δθ = −ηg. Global norm clipping limits that update’s gradient magnitude before the optimizer uses it.
  2. Use g_clipped = min(1, c/‖g‖₂)g for a positive threshold c. For g = (3,4) and c = 2, the norm is 5 and the clipped gradient is (1.2,1.6). Its direction is preserved.
  3. Small SGD batches, oversampling minority classes, and increasing batch size address other concerns or change the noise of updates. None is the specific direct safeguard described here.

What to watch for

The printed option letters are duplicated in the PDF. “D” refers to the fourth option about rescaling by the norm. Clipping does not enlarge small gradients.

QUESTION 07 / 56 · RNNs#7

RNN parameters becoming NaN

An RNN’s parameters become NaN. Which listed cause is most likely?

Archived key: B

B · Exploding gradients.

Why this answer follows

  1. Backpropagation through time multiplies recurrent Jacobians across many steps. If their product grows strongly, the gradients and subsequent parameter updates can become enormous.
  2. Overflow can create infinity, and later operations such as infinity minus infinity can yield NaN. Clipping and inspecting learning rate, activations, loss, and numerical stability help diagnose the failure.
  3. Vanishing gradients usually make updates too small. ReLU on a large finite positive number simply returns that number. A large sigmoid input mathematically saturates toward 1 rather than inherently producing NaN.

What to watch for

NaN is not a unique signature: invalid input, unstable formulas, division by zero, or a large learning rate can also cause it. B is the best listed explanation.

Can ordinary neural-network regularization such as L2 be applied to graph neural networks?

Archived key: B

Why this answer follows

QUESTION 09 / 56 · Graphs#9

Neighborhood aggregation

What is the primary purpose of the aggregation function in a GNN?

Archived key: A

A · Combine information from a node’s neighbors.

Why this answer follows

  1. For a target node v, collect messages from neighbors N(v). A sum, mean, max, or appropriately constructed attention aggregation converts that variable-size collection into a vector.
  2. For neighbors with scalar values 2 and 4, a mean aggregator returns 3. The update then combines this neighbor information with the target node’s own representation.
  3. Dimensionality reduction is not the defining purpose. Node classification and edge prediction are downstream tasks that may use the resulting embeddings.

What to watch for

Separate aggregation, the node update, and the prediction head. An aggregate is not automatically a class label.

QUESTION 10 / 56 · CNNs#10

Are pooling layers required?

Must every CNN include pooling layers?

Archived key: C

C · No; pooling is commonly used for spatial reduction.

Why this answer follows

  1. Convolution supplies local receptive fields and parameter sharing. Neither property requires a separate pooling layer.
  2. Pooling reduces spatial resolution and downstream computation. It can discard detail and sometimes reduce overfitting or add limited tolerance to small shifts. Strided convolutions can also perform downsampling.
  3. A is wrong because convolution itself uses spatial neighborhoods. B is wrong because pooling is not required to prevent vanishing gradients. D mentions nonlinearity, but spatial reduction is the intended main role; average pooling is linear.

What to watch for

Pooling is an architectural choice. Max pooling is nonlinear, but not every pooling operator is nonlinear or a generalization guarantee.

QUESTION 11 / 56 · Foundations#11

Why ReLU is nonlinear

Why is ReLU nonlinear even though each of its two pieces is linear?

Archived key: C

C · Its slope changes at zero.

Why this answer follows

  1. ReLU(x) = max(0,x). Its slope is 0 for x < 0 and 1 for x > 0, so no single linear function describes it over the whole real line.
  2. A direct linearity test gives ReLU(1 + (−1)) = 0, while ReLU(1) + ReLU(−1) = 1. Failure of additivity proves nonlinearity.
  3. A incorrectly says it only outputs positive values; zero is possible. B describes only the nonnegative branch. D describes its piecewise form, but having two linear pieces alone is not a sufficient explanation: pieces with the same rule could form one global linear map.

What to watch for

Piecewise linear and globally linear are different properties. The key fact is the different slopes, not just having a case distinction.

QUESTION 12 / 56 · Foundations#12

Why hidden nonlinearities matter

Why do neural networks need nonlinear transformations between layers?

Archived key: C

C · They make nonlinear relationships representable.

Why this answer follows

  1. Two linear layers collapse: W₂(W₁x) = (W₂W₁)x. With biases, they still collapse to one affine map: W₂W₁x + W₂b₁ + b₂.
  2. A nonlinearity between them prevents that general collapse. Different regions of input space can activate different hidden units, allowing the model to express more complicated boundaries.
  3. A reverses the point by limiting the model to linear separation. B and D describe possible practical outcomes, not the fundamental increase in representational capacity.

What to watch for

Adding depth without nonlinearities does not by itself create a nonlinear predictor. More parameters and more expressive function classes are not the same thing.

QUESTION 14 / 56 · Classical ML#14

Decision-tree overfitting

Which listed disadvantage of decision trees is valid?

Archived key: C

C · Decision trees are prone to overfitting.

Why this answer follows

  1. A deep tree can keep splitting until it isolates training examples, including noisy ones. Those branches may fail on new data.
  2. Single small trees are often interpretable, so A’s blanket claim of lacking interpretability is false. Prediction follows one root-to-leaf path and does not usually compare against the full training set as basic kNN does, so B is not a general disadvantage.
  3. Because A and B are not generally true, “all of the above” is also wrong. Depth limits, pruning, minimum leaf sizes, and ensembles can help control the problem.

What to watch for

A tree can be highly interpretable and still overfit. Interpretability does not establish accuracy on unseen data.

Shared GNN parameters and graph size

How can a GNN accept graphs with different numbers of nodes and different connectivity?

Archived key: B

B · Reuse a fixed set of shared parameters.

Why this answer follows

  1. A typical layer applies the same feature transform and aggregation rule at every node. Its matrices depend on feature widths, not on the total number of nodes.
  2. If each node has two features, a 2×2 shared transform can be applied to three nodes or a thousand nodes. The adjacency structure determines which messages are combined.

Feature definitions and widths must remain compatible. Being able to compute outputs on a new graph does not guarantee good predictive accuracy.

QUESTION 16 / 56 · Graphs#16

Directed graphs in GNNs

Which listed approach is not a common general way to handle directed edges?

Archived key: C

Why this answer follows

  1. Direction distinguishes u→v from v→u. A model can preserve that distinction using separate incoming and outgoing aggregators, relation-specific transforms, or edge-aware messages.

QUESTION 17 / 56 · Graphs#17

Graph autoencoders

Which description best fits a graph autoencoder?

Archived key: A

A · A network for unsupervised representation learning on graphs.

Why this answer follows

  1. An encoder maps graph structure and possibly node features into latent embeddings. A decoder reconstructs a target such as adjacency or node features.
  2. For an edge reconstruction example, a decoder can compute σ(zᵤᵀzᵥ), an edge score from two learned node vectors. Training compares reconstructed structure with the observed graph rather than requiring supplied node-class labels.

Unsupervised learning can still create training targets from the data itself. Modern terminology may also describe reconstruction as self-supervised.

QUESTION 18 / 56 · Training#18

Initialization versus regularization

Which is not normally classified as a regularization technique: pruning, L2, random initialization, or augmentation?

Archived key: C

C · Random weight initialization.

Why this answer follows

  1. Initialization chooses the starting parameter values. Different initial values let hidden units learn different features and can improve signal and gradient propagation.
  2. Pruning reduces model complexity; L2 changes the objective to penalize large weights; augmentation provides transformed training examples with valid labels. These are standard ways of influencing generalization.
  3. Initialization can affect the eventual solution and its generalization, but its usual role is enabling effective optimization. That distinction makes C the intended answer.

What to watch for

Randomness alone does not make an operation regularization. Ask which mechanism it changes and why.

QUESTION 21 / 56 · Foundations#21

Activation range and derivative

Which primary activation properties govern their use: range and slope, range alone, probability outputs alone, or probability outputs and slope?

Archived key: A

A · Both output range and response rate (derivative).

Why this answer follows

  1. The range controls what an activation can represent: sigmoid gives values between 0 and 1, tanh gives values between −1 and 1, and ReLU gives nonnegative values with no upper bound.
  2. The derivative controls how gradients pass through it. Sigmoid’s derivative σ(x)(1−σ(x)) becomes small at saturated inputs; ReLU has slope 1 for positive inputs and 0 for negative inputs.
  3. B omits gradient behavior. C and D focus too narrowly on probability outputs; most hidden activations are learned feature values, not probabilities.

A number in [0,1] is not automatically a calibrated probability. Output interpretation also depends on the task and training objective.

QUESTION 22 / 56 · Training#22

Preprocessing without data leakage

Which split should supply fitted preprocessing statistics, such as feature means?

Archived key: B

Read with care. Key correction: printed B → study answer A.

QUESTION 23 / 56 · Training#23

BatchNorm in training and evaluation

Which BatchNorm statement is true? A says training uses the current mini-batch’s mean and variance.

Archived key: A

A · Training normally uses current mini-batch statistics.

Why this answer follows

  1. For one feature, BatchNorm standardizes with x̂ = (x−μ_B)/√(σ²_B+ε), then applies y = γx̂+β. The scale γ and shift β are learned parameters.
  2. Ordinary evaluation mode uses stored running mean and variance from training instead of the current test mini-batch. This makes an example’s prediction independent of which other examples happen to be in that batch.
  3. C and D confuse feature standardization with dividing an input vector by its L1 or L2 norm. Even using the full training set as the batch does not turn centering and variance scaling into either norm normalization.

What to watch for

BatchNorm is mode-dependent. The usual answer assumes running statistics are enabled; alternative implementations or explicit configurations can behave differently.

QUESTION 25 / 56 · RNNs#25

RNNs can have both gradient problems

Which RNN statement is false? A claims RNNs have vanishing gradients but never exploding gradients.

Archived key: A

A · RNNs can suffer from both.

Why this answer follows

  1. Unroll the recurrent computation across time. A gradient from a late step to an early step contains a product of local Jacobians.
  2. In a scalar toy recurrence with derivative a, a path over T links contributes aᵀ. For a=0.5 this shrinks; for a=2 it grows. Real networks use matrices and activation derivatives, but the repeated-product mechanism remains.

k-means initialization and local solutions

What can happen if k-means starts with poorly chosen centroids?

Archived key: B

B · It may converge to a poor local solution.

Why this answer follows

  1. Lloyd’s algorithm alternates nearest-center assignment and recomputing cluster means. Each step does not increase the squared-distance objective, but that does not prove global optimality.
  2. Different starting centers can produce different stable assignments. The review gives {1,3,5,9}, k=2: centers (2,7) have objective 10, while centers (3,9) have objective 8. Both are stable under the alternating steps.
  3. Poor initialization does not inherently prevent the algorithm from running, change k, or turn it into hierarchical clustering. Multiple restarts and careful initialization can improve results.

What to watch for

Convergence means the chosen iteration has stabilized, not that no better clustering exists.

kNN regression uses an average

How does ordinary unweighted kNN predict a continuous regression target?

Archived key: A

A · Average the target values of the nearest neighbors.

Why this answer follows

  1. Find the k closest training inputs using the chosen distance rule. Retrieve their numeric target values.
  2. For k=3 and targets 2,5,11, predict (2+5+11)/3=6. Averaging differs from the majority vote used for class labels.
  3. B describes classification voting. C describes copying one neighbor rather than general k-neighbor regression. D describes an optimization procedure not required for basic kNN prediction. Distance-weighted kNN is a variant; the unweighted mean is the intended default.

What to watch for

Average targets, not the feature vectors or the distances. “Nearest” selects which examples contribute.

QUESTION 52 / 56 · Gradients#52

Residual connections and the chain rule

How do residual connections help gradient flow?

Archived key: A

A · They add an identity path alongside a learned transformation.

Why this answer follows

  1. A residual block computes y=x+F(x). The derivative with respect to x is I+J_F(x), so the gradient has a direct identity-path contribution as well as the contribution through F.
  2. For a scalar example with upstream gradient 3 and F′(x)=−0.25, the gradient to x is 3(1−0.25)=2.25. It is the sum of the two path contributions, not a fixed added constant.
  3. The network still contains its learned layers and is not forced to make F zero. Thus B’s claimed layer removal, C’s constant-gradient addition, and D’s mandatory identity function are incorrect.

Primary reference: He et al.: Deep Residual Learning ↗

What to watch for

The identity path improves training opportunities; it does not guarantee gradients can never shrink or cancel. In the example they shrink from 3 to 2.25.

QUESTION 53 / 56 · Gradients#53

Clipping does not fix vanishing gradients

How can gradient clipping address vanishing gradients?

Archived key: D

D · Standard clipping is not a remedy for vanishing gradients.

Why this answer follows

  1. Norm clipping uses min(1,c/‖g‖) as its scale factor. That factor never exceeds 1, so clipping cannot enlarge a small gradient.
  2. For g=(0.03,0.04), ‖g‖=0.05. With c=1, the factor is min(1,20)=1, leaving g exactly unchanged.
  3. A and C incorrectly suggest amplification. B describes controlling large gradients but does not turn that into a fix for small ones. Residual pathways, gating, and appropriate activation and initialization choices address different causes of poor gradient flow.

What to watch for

Normalizing every gradient to unit norm is not the same operation as clipping only norms above a threshold.

Try it from memory

Clip (3,4) and (0.03,0.04) with threshold 1, and compare the two scale factors.

QUESTION 54 / 56 · Gradients#54

Why gradients can vanish with depth

Why are long deep-network paths especially susceptible to vanishing gradients?

Archived key: C

C · Repeated derivatives can make their product exponentially small.

Why this answer follows

  1. Backpropagation multiplies local derivatives along a path. If each scalar factor has magnitude 0.5, a path with 20 factors contributes 0.5²⁰≈9.54×10⁻⁷.
  2. Early layers can therefore receive a very weak learning signal even while later layers receive useful gradients. Saturated sigmoid units are a common source of small derivative factors.
  3. Shallow models also use gradient-based learning. Parameter count, compute cost, and overfitting are separate concerns; none alone explains the chain-rule multiplication mechanism in C.

What to watch for

Depth does not guarantee vanishing: products depend on weights, activations, and paths. Products can also grow or remain stable.

QUESTION 55 / 56 · CNNs#55

What “deep” means in a CNN

Which choice captures what “deep” refers to in a CNN: filter count, filter size, number of convolutional layers, or pooling count?

Archived key: C

C · The number of stacked convolutional layers is the best listed answer.

Why this answer follows

  1. Depth counts successive learned transformations along an input-to-output path. In the options, stacking more convolutional layers is the relevant increase in depth.
  2. Adding filters increases the width or channel count of a layer. Enlarging filters increases spatial receptive span and parameter count per filter. Neither is the same as adding sequential layers.
  3. Pooling count alone does not define a deep CNN. More generally, architecture-specific depth counts can include fully connected layers or count blocks differently, so read the stated convention.

What to watch for

Depth and width describe different dimensions of architecture. Increasing either can add computation and capacity, but by different mechanisms.
