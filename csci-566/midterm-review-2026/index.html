Why is changing the activation the odd one out? (ELI5)

Imagine 100 practice photos and 100 new photos. The model gets 100 practice photos right but only 46 new ones. Like memorizing a practice exam, it learned details that do not transfer well. A remedy should make memorization harder or provide better evidence—not simply swap two saturating activations.

Important distinction

A large gap is evidence to investigate, not a proof that every regularizer will help. B is the least standard remedy among these choices.

Archived key: B

B · Replacing tanh with sigmoid is not a standard overfitting remedy.

Step by step

  1. The network fits the training set perfectly but makes many mistakes on unseen examples. This is consistent with overfitting, although a distribution shift or a bad split could also create a gap.
  2. L2 adds a cost for large weights; a smaller model limits capacity. Both can discourage memorizing training-specific details. BatchNorm can introduce a useful regularizing effect during training, although it does not guarantee better generalization.
  3. Tanh and sigmoid both saturate. Swapping one for the other does not directly constrain model complexity or increase the training information. Choose changes using validation performance, then evaluate the final choice on test.

Q3 topic: Zero initialization and first-layer gradients

Zero initialization and gradient flow

All network parameters start at zero. After one forward/backward/update step, what can happen to the first-layer weights?

Choose your answer

Not answered yet

Read with care. Architecture-dependent key: A in the archive; D for the first update of a standard all-zero multilayer network.

Why does the architecture change the answer? (ELI5)

In a single linear neuron with target 1 and input (1,−1), zero weights update to (2η,−2η). But put a zero-weight layer between the loss and the first hidden layer, and that backward signal is multiplied by zero. The first-layer weights then stay zero on that first update.

Compare the ideas

ConceptWhat it doesWhat this means here
One linear layerIts gradient can depend directly on x and yThe update can have either sign
All-zero multilayer networkThe backward signal crosses a zero downstream matrixFirst hidden-layer gradient is zero on the first pass
Identical hidden unitsThey can receive identical updatesThey may never learn different features

Important distinction

B and C impose an unjustified fixed sign. A needs an architecture that permits a nonzero first-layer gradient; zero initialization alone does not ensure that.

Connection to your Fall 2026 review

95–104, 122–125.

Remember

  • An update is determined by its full gradient path.
  • Zero initialization does not imply one universal sign.
  • Random hidden-weight initialization helps break symmetry.

Primary reference: Stanford CS231n: initialization and symmetry ↗

Trace the derivation and original answer choices

Archived key: A

Printed A is possible for some models; the question does not specify enough to make it universal.

Step by step

  1. For a one-layer linear model, L = (wᵀx − y)² gives ∇w L = 2(wᵀx − y)x. At w = 0, the update is w ← 2ηyx. With y = 1 and x = (1, −1), the new weights are (2η, −2η), so both signs are possible.
  2. For a conventional multilayer network, the first hidden-layer gradient contains the next layer’s weight matrix: δ₁ = (W₂ᵀδ₂) ⊙ g′(z₁). If W₂ = 0, then δ₁ = 0 on this first pass. Consequently W₁ remains zero after that simultaneous update: option D in this setting.
  3. Even when identical hidden units later receive nonzero updates, symmetric units can remain identical. Random initialization breaks that symmetry; it is not a promise that every weight will have a particular sign.

Original answer breakdown

ChoiceExplanation
A. First-layer weights may be positive or negativePrinted key. Possible for a one-layer linear model whose gradient depends directly on the input and target.
B. All first-layer weights become negativeNo fixed negative sign follows from zero initialization.
C. All first-layer weights become positiveNo fixed positive sign follows from zero initialization or “gradient direction.”
D. All first-layer weights remain zeroTrue for the first simultaneous update of a conventional all-zero multilayer network because the next weight matrix blocks the gradient.

Exam takeaway

A zero start does not determine an update’s sign. Check the architecture and the whole gradient path before accepting the archived A.

Why can exploding gradients produce NaN? (ELI5)

Repeated doubling gives 2,4,8,16,… . A long enough chain can exceed the largest number the computer can store. If later arithmetic combines infinities invalidly, such as infinity minus infinity, the result becomes NaN.

Compare the ideas

ConceptWhat it doesWhat this means here
Vanishing gradientRepeatedly shrinks the backward signalUpdates become ineffective
Exploding gradientRepeatedly magnifies the backward signalUpdates can overflow
NaNAn invalid numerical resultInspect the entire numerical pipeline

Important distinction

NaN is not a unique signature: invalid input, unstable formulas, division by zero, or a large learning rate can also cause it. B is the best listed explanation.

Connection to your Fall 2026 review

108–112, 160–168.

Remember

  • Explosion is the best listed explanation, not the only possible NaN cause.
  • Check inputs, losses, learning rate, and gradient norms.
  • A large finite ReLU input alone is not a NaN mechanism.
Trace the derivation and original answer choices

Archived key: B

B · Exploding gradients.

Step by step

  1. Backpropagation through time multiplies recurrent Jacobians across many steps. If their product grows strongly, the gradients and subsequent parameter updates can become enormous.
  2. Overflow can create infinity, and later operations such as infinity minus infinity can yield NaN. Clipping and inspecting learning rate, activations, loss, and numerical stability help diagnose the failure.
  3. Vanishing gradients usually make updates too small. ReLU on a large finite positive number simply returns that number. A large sigmoid input mathematically saturates toward 1 rather than inherently producing NaN.

Original answer breakdown

ChoiceExplanation
A. Vanishing gradientsUsually make learning signals too small; they do not ordinarily overflow parameters.
B. Exploding gradientsBest listed cause. Huge updates can cause overflow and invalid arithmetic.
C. ReLU on a very large inputFor a finite positive input, ReLU simply returns that input; this alone does not explain NaN.
D. Sigmoid on a very large inputMathematically approaches 1; stable sigmoid implementations handle saturation without NaN.

Exam takeaway

NaN suggests checking exploding gradients and numerical stability. Vanishing gradients usually cause tiny updates instead.
