2. Return to the core idea: learning a function

The course’s base formulation remains a mapping from input x to output y. There may be an ideal target function f*, but in practice the learner seeks a good approximation f(x; W).

y ≈ f(x; W)
Choose W so that a loss measuring prediction error is small.

Historically, different applications trained different specialized functions. Foundation models change the scale of the idea: one large model may support many mappings. Zhao nevertheless returned to the specialized case first so students could see what is inside a weighted nonlinear function.

Why deep learning was attractive

  • Approximation capacity: the universal approximation result motivates neural networks as flexible function approximators, while remaining a theoretical guarantee rather than a promise that any finite network will train successfully.
  • Nonlinearity: stacked linear maps alone cannot represent the complex boundaries desired.
  • Hierarchy: layers can transform low-level signals into progressively more condensed representations.
  • End-to-end feature learning: unlike much classical ML, deep learning can learn useful features together with the predictor instead of depending entirely on hand-engineered features.
Continuity with earlier weeksTraining still means choosing weights by minimizing a loss. Random search and an analytical solution work only in limited cases; gradient-based numerical optimization is the practical route for larger nonlinear models.
Recall check: What is automated feature extraction?

The network learns intermediate representations from the input while learning the final prediction. The practitioner does not have to manually specify every useful feature before fitting the model.

3. What a neural network is

Zhao’s compact description was a set of neurons connected in a nonlinear way. Biological neurons are a historical motivation, not a close scientific equivalence.

Neuron

Receives inputs, combines them with learned weights and a bias, then applies a transformation.

z = Wx + b
a = φ(z)

Layered network

The activations produced by one layer become the inputs to the next. “Deep” means multiple representation layers, though modern models are vastly larger than early two-layer examples.

h₁ = φ(W₁x+b₁)
h₂ = φ(W₂h₁+b₂)
ŷ = W₃h₂+b₃

A diagram drawn symmetrically often shows a fully connected network: every unit in one layer connects to every unit in the next. Real networks need not be fully connected; connections can be removed, localized, or skipped.

Draw a two-hidden-layer network and annotate each weight matrix, bias, preactivation, and activation.

4. Forward propagation = prediction / inference

The forward pass executes the graph from inputs to outputs, one layer at a time. It produces the prediction and caches intermediate values that may later be needed for gradient computation.

  1. Feed x into the first layer.
  2. Compute each layer’s weighted combination and nonlinear activation.
  3. Use the previous layer’s output as the next layer’s input.
  4. At the output, obtain scores, probabilities, or another task-specific prediction.

LLM connection: autoregressive decoding

For a prompt such as “the light is,” the model repeatedly predicts one next token, appends it, and predicts again. Zhao used the transformer’s saved key/value representations as an example of how a forward pass produces reusable intermediate results. The detailed transformer mechanism was explicitly deferred to a later week.

Do not over-study yetKnow the idea that transformer inference caches intermediate representations to avoid recomputing the whole prefix. The lecture did not yet teach attention, Q/K/V derivations, or transformer internals.
Recall check: Why is the forward pass sequential across layers?

Layer ℓ cannot be evaluated until the activation from layer ℓ−1 is available. Each layer transforms the preceding representation into the next one.

5. Why the network needs nonlinearity

Exam priorityZhao explicitly said this question is regularly used on the midterm: without nonlinear activations, many stacked layers collapse into one linear transformation.
h = W₂(W₁x+b₁)+b₂
= (W₂W₁)x + (W₂b₁+b₂)

The composition is still of the form W′x+b′. Adding depth without nonlinear activation therefore does not buy a nonlinear decision boundary. A function such as ReLU creates a bend/piecewise behavior that a single straight linear map cannot absorb.

Answer check: Explain this without algebra.

Chaining operations that only stretch, rotate, rescale, and shift remains one combined stretch/rotate/rescale/shift. A nonlinear activation changes the shape of the mapping so later layers can build more complex boundaries.

7. Width, depth, capacity, and overfitting

Adding neurons and layers increases the variety and complexity of functions the network can express. In lecture visuals, more hidden units created more intricate decision boundaries.

Benefit

Greater model capacity can fit more complex patterns.

Risk

Greater capacity can overfit when the available data and regularization do not support it.

Regularization adds a preference for simpler/smaller weights. The combined training objective was framed as:

Ltotal = Ldata + λR(W)

Ldata measures mismatch between prediction and ground truth; R(W) penalizes model complexity; λ controls that tradeoff.

8. From output scores to probabilities

The network’s last layer may output raw scores (logits). Softmax exponentiates and normalizes them so the values are positive and sum to one.

p(y=i|x) = exp(zᵢ) / Σⱼ exp(zⱼ)

Zhao connected this to next-token prediction: given candidate continuations such as red, blue, and green, the model produces a probability distribution. If the training continuation is “red,” the loss should drive the model to assign “red” a higher probability next time.

  1. Forward pass produces logits.
  2. Softmax turns logits into probabilities.
  3. Compare the predicted distribution with the ground-truth target.
  4. Backpropagation computes how each weight contributed to the loss.
  5. An optimizer updates weights to reduce future loss.
Recall check: Does softmax itself train the model?

No. Softmax converts scores into a normalized distribution. The loss and backward/optimization process determine how weights change.

9. Computational graphs and backpropagation

A computational graph breaks a composite computation into elementary nodes. Modern frameworks need the forward computation; automatic differentiation then applies local derivative rules backward through the graph.

Mini-example: f=(x+y)z

q = x + y
f = qz

∂f/∂q = z    ∂q/∂x = 1
∂f/∂x = (∂f/∂q)(∂q/∂x) = z

The pattern generalizes: at a node, multiply the upstream gradient by that node’s local gradient. The result flows farther toward the input.

Conceptual — understandBackpropagation proceeds from the final loss toward earlier layers because the chain rule requires the derivative of later computations before earlier parameters’ effects can be assembled. Zhao said students would not be tested on laborious hand calculation of the full example.

Training cycle

  1. Forward: compute activations, prediction, and loss.
  2. Backward: propagate gradients from the loss to every learnable weight.
  3. Update: move parameters in a direction that lowers the loss.
  4. Repeat on further data.

A graph is not necessarily unique: algebraically equivalent computations can be arranged differently. A practical graph should be easy to express and optimize.

Explain “upstream gradient × local gradient” using a two-operation computation of your own.

10. Why training costs more than inference

Inference mostly performs the forward computation. Training must also retain activations/checkpoints needed by the backward pass, compute gradients, and update parameters. For billions of parameters—even at reduced precision—the memory burden is much larger.

External memory

Keep useful information outside model weights and retrieve it when needed. Agent memory was the modern example: adaptation may happen through stored/retrieved context rather than weight updates.

Partial parameter update

Freeze most parameters and update only a smaller subset. LoRA (low-rank adaptation) was previewed as a prominent approach; its mechanism was deferred.

Lecture boundaryAgent memory and LoRA were motivating previews, not full technical treatments. Know the two resource-saving ideas; do not invent a LoRA derivation from this lecture.

FailureWhat happensWhy it mattersLecture remedies
Vanishing gradientRepeated chain-rule multiplication makes the signal to early layers extremely small; saturated sigmoid derivatives are a major example.Early layers barely update, so credit assignment across a deep network fails.Prefer ReLU-family activations; batch normalization was previewed as another aid.
Exploding gradientGradient norms grow extremely large.A single update can jump far away, destabilize loss, or produce infinity/NaN.Gradient clipping: preserve the direction while limiting the step/norm; use checkpointing and tune cautiously.
Dying ReLUA ReLU remains in its negative, zero-gradient region.The unit stops contributing learning signal.Leaky ReLU / ELU variants; avoid overly aggressive updates.
Likely comparison questionBe able to connect activation choice to derivative behavior: sigmoid saturation → vanishing gradient; ReLU’s negative branch → dying units; very large updates → exploding gradients and clipping.
Recall check: Why is clipping easier than “un-vanishing” a gradient?

An overly large vector can be rescaled or capped while retaining a useful direction. Once repeated multiplications have reduced a learning signal almost to zero, little information remains to recover; the architecture/activation/normalization must prevent that collapse.

12. Opening motivation for convolutional networks

The lecture then shifted from generic feed-forward networks to data-specific architectures. CNNs exploit image structure: nearby pixels are correlated, visual patterns are local, and the same kind of pattern may appear at many positions.

Why not flatten everything into a fully connected layer?

  • Parameter count becomes enormous. Zhao’s 200×200-image example illustrated how quickly dense connections can reach billions of parameters.
  • Flattening treats pixels independently and discards their 2-D spatial organization.
  • A locally connected layer helps, but assigning separate weights to every location still misses the efficiency of sharing one detector across positions.

Convolution’s design idea

A small learnable filter slides over the image. At every location it computes a local weighted sum. Reusing the same filter weights across locations is parameter sharing; applying several filters produces several activation maps.

input: 32 × 32 × 3
filter: 5 × 5 × 3, stride 1, no padding
one filter output: 28 × 28
six filters output: 28 × 28 × 6

The filter depth matches the input depth (RGB gives three channels). Each filter has its own learned weights and detects a different pattern. This section introduced the mechanism; stride, padding, pooling, and exact output-size calculations continue in Week 5.

Conceptual framingCNN hierarchy mirrors the lecture’s broader story of learned representation: early filters can respond to simple edges/colors; deeper layers can combine them into more complex patterns. Biological vision was motivation, not proof of equivalence.
Recall check: What is gained by sharing a filter?

The network can detect the same local pattern anywhere in the image with one set of weights. That preserves spatial reasoning while using far fewer parameters than separate weights for every location.
